# Ruins_KSW 편집 안내

최신 작업: 2026-09-27 — 사용자가 정리한 씬을 기준으로 천장을 개별 큐브로 분리하고 이름을 단순화했다.

Unity에서 `Assets/Scenes/Ruins_KSW.unity`를 연다. 현재 이미 열려 있다면 외부 변경 내용을 Reload하거나 씬을 다시 연다. 이전 GrandHall은 사용자가 Ruins_KSW로 이름을 바꿨으므로 이 파일이 현재 작업 씬이다.

## Hierarchy

`Ruins` 아래에 짧은 이름으로 묶었다.

- `Pillars`: 기존 기둥 10개. 기둥 자체의 위치·모양과 Left/Right 이름은 유지했다.
- `Floor`: 기존 양쪽 단상과 연결 바닥. `Cube`, `Cube (1)`처럼 정리했다.
- `Walls`: 벽과 벽기둥. `Cube`, `Cube (1)`처럼 정리했다.
- `Pillars_Parts`: 기둥 위 받침과 보. 사용자 그룹 이름을 유지하고 자식 이름에 복제 번호를 붙였다.
- `Ceiling`: 아래처럼 나뉜 천장 부재.
- `End_Walls`: 사용자 그룹 이름을 유지하고 각 부재를 `Cube`, `Cube (1)`처럼 정리했다.

## 천장 수정

`Ceiling`을 펼치면 다음처럼 보인다.

- `Frame`, `Frame (1)` ~ `Frame (4)`: 기존 천장 테두리 다섯 개. 각각 독립된 큐브 8개로 구성한다.
- `Roof`: 위를 덮는 면. 가로 8개 × 길이 6구간으로 나눈 큐브 48개다. **사용자가 꺼 둔 상태를 유지했다.** 필요하면 이 그룹의 활성 체크를 켠다.
- `Side`, `Side (1)`: 측면 천장. 각각 큐브 6개다.

1. 테두리 전체를 옮기려면 `Frame` 그룹을 선택한다.
2. 일부 각도만 고치려면 그 아래의 `Cube`를 선택한다.
3. Inspector의 Position / Rotation / Scale을 바꾸거나 W / E / R 도구를 사용한다.
4. 필요하면 원하는 부재를 선택하고 Ctrl+D로 복제한다.

모든 새 천장 부재는 일반 Cube와 Box Collider다. 연결된 프리팹이나 실행 스크립트가 없어서 한 조각을 바꿔도 다른 조각이 함께 바뀌지 않는다. ProBuilder 편집이 필요할 때는 원하는 큐브만 ProBuilderize하면 된다.

## 유지 및 확인

- 카메라와 조명 설정, 사용자 오브젝트 활성 상태, 천장 외 기존 형태와 월드 배치는 유지했다.
- 새로운 재질이나 텍스처는 추가하지 않았다.
- 저장 후 다시 열어서 천장 부재 100개가 개별 큐브/Box Collider로 남는지 확인했다.
- 지붕을 잠시 켜고 289개 지점의 연결을 검사한 뒤 사용자의 꺼짐 상태로 되돌렸다.
- 현재 씬 렌더 전후를 비교했다. 큐브 조각 연결부의 각진 형태 외에는 구도와 분위기를 유지했다.

수정 전 씬 백업은 프로젝트 `UserSettings/RuinsSceneBackups` 아래에 저장한다. 자동으로 덮어쓰는 생성 스크립트는 프로젝트에 추가하지 않았다.
